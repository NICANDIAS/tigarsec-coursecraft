Admin: AI Provider

Configure which AI service marking, scheme-of-work generation, and lesson generation actually use - from here, not from the server's .env file, so switching (e.g. if one service is blocked on your network, or you want to try a free option) doesn't need a redeploy. Only one configuration is active at a time.

Marking and spec parsing use whichever provider is active here. Scheme-of-work and lesson generation are different - these are drafts you review/edit before use, so they default to Ollama (free) automatically, even once a paid provider is active for marking - activating a paid provider here never silently starts charging for these too. Override this specifically with "Use for draft generation" below if you genuinely want it on a paid provider as well.

Use "Test connection" on any saved provider to check reachability and credentials from THIS server, without needing to try a real generation task first - useful for confirming whether a service is actually reachable on your network (e.g. if a college firewall blocks a specific domain) before relying on it.
