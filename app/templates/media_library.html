Media library

What this is for: when generating a lesson PowerPoint, each slide that wants an image tries three sources in order: (1) a real photo from Unsplash, if you've set UNSPLASH_ACCESS_KEY in .env, (2) a tagged image from THIS library that matches the slide's topic keywords, (3) a plain generated placeholder graphic if neither of those finds anything. Upload and tag images here to improve source #2 - useful if you don't want to set up Unsplash, or want specific images (real screenshots, diagrams, photos from your own workplace/labs) to show up instead of generic stock photos. Shared with every teacher once uploaded.
